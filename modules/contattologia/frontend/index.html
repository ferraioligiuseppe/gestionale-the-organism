Geometria inversa · ortocheratologia
Curva inversa e di allineamento sono calcolate, non scelte: l'allineamento segue la cornea, l'inversa colma il dislivello.
Lente morbida
Nelle morbide il BC non predice l'appoggio: due lenti «8.60» possono differire di 400 µm di sagitta.
Defocus periferico · controllo miopico
Meccanismo ottico: il defocus miopico simultaneo sulla retina periferica, non un rimodellamento corneale.
Orto-K morbida · simulazione di rigidità
Modello a piastra incastrata: ordine di grandezza, non progetto ingegneristico. Solo simulazione, non da provare sul paziente.
Progetto sclerale
La sagitta, non il raggio, è il parametro di controllo. L'atterraggio è allineato quando il suo angolo eguaglia quello sclerale.

Come inserirlo nel gestionale

Il file è autonomo: nessun font, script o foglio di stile esterno. Funziona offline e dentro un iframe.

Streamlit — salva il file come modules/lac/rgp_multicurva.html e richiamalo da ui_lac.py:

import streamlit.components.v1 as components
from pathlib import Path

def render_progettista_rgp():
    html = Path(__file__).with_name("rgp_multicurva.html").read_text(encoding="utf-8")
    components.html(html, height=2100, scrolling=True)

Valori verso la pagina che lo ospita — a ogni modifica il widget invia al parent:

window.addEventListener("message", (ev) => {
  if (ev.data && ev.data.type === "rgp:change") console.log(ev.data.payload);
});

Il payload contiene cornea, zonaOttica, curve[], metriche e specifica: la stessa struttura del pulsante JSON, pronta da salvare in PostgreSQL.

API diretta — window.RGP.getState() restituisce lo stato, window.RGP.setState({...}) lo imposta (utile per riaprire un progetto salvato).

Il profilo di clearance è calcolato geometricamente fra la superficie posteriore costruita e un modello conico della cornea (raggio apicale ed eccentricità inseriti). Predice l'appoggio, non la fisiologia: il pattern fluoresceinico reale dipende anche da spessore lacrimale, palpebre e assestamento. Va sempre confrontato con la lente di prova.
